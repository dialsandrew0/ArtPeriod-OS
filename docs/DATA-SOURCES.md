# Data Sources & Licensing

Prioritize open, properly licensed sources:

- Met Museum CC0
- Wikidata (CC0)
- Getty vocabularies (respect ODC-BY and attribution requirements)
- Other open collection APIs with clear terms

Gated commercial databases may be added later only with clear user-facing disclosure and cost model.

Every ingested record must carry its license and required attribution so the product never ships contaminated data.
