# Honesty Protocol

Every analysis card or valuation must expose:

- **Observed** — directly visible or measurable facts
- **Inferred** — model or database claims
- **Confidence** — score or band + reason
- **Evidence / Sources**
- Explicit **insufficient data** when appropriate

Never collapse inference into observation. This protocol is inherited from ArtPeriod Field Triage and is non-negotiable in ArtPeriod-OS.
